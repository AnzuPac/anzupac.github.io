# Портфолио — Даниил, AI Engineer

Одностраничное портфолио: проекты, стек, контакты.

## Публикация (любой из вариантов)

1. **GitHub Pages**: создать репозиторий `portfolio`, загрузить содержимое этой папки,
   Settings → Pages → Source: `main` / root. Сайт будет на `https://<логин>.github.io/portfolio/`.
2. **Netlify / Vercel**: перетащить папку в дашборд — деплой за минуту.
3. **Свой сервер**: скопировать папку в каталог nginx и открыть `index.html`.

После публикации — вписать ссылку в резюме вместо «Портфолио и код — по запросу».
